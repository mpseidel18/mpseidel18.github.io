Audio FX & Synth

AeroSynth JUCE Plugin

A subtractive dual-oscillator synthesizer plugin written in C++ using the JUCE framework, designed with a custom hardware-accelerated Vector GUI skin.

C++ JUCE DSP VST3/AU

Implementation Details: The plugin utilizes an optimized custom DSP loop for its dual-oscillators, ensuring low-latency processing. The hardware-accelerated Vector GUI separates audio thread logic from UI rendering for stable performance.

Unity VR

VR MIDI Visualizer

An immersive Virtual Reality environment where standard MIDI inputs map to physical physics-based graphics, rendering glowing orb particles that interact with sound waves.

Unity C# XR Interaction Midi Device API

Implementation Details: Built with Unity's XR Interaction Toolkit. The codebase features a custom C# event system that hooks into the Midi Device API to parse input velocities and map them directly to the physics engine properties of the particle orbs.

Webcam Theremin

An interactive browser-based instrument that translates your hand movements captured via webcam or an uploaded video into real-time theremin sounds using the Web Audio API.

Upload Video Source
JavaScript Web Audio API MediaPipe OpenCV

Implementation Details: Employs MediaPipe for robust hand-tracking and OpenCV.js for localized gesture smoothing. The frontend coordinates these asynchronous visual tracking results with the Web Audio API's oscillator frequency and gain nodes to produce continuous sound.
